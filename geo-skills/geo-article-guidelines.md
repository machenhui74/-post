# GEO引导性文章写作规范

> 目的：在各个平台上投放优质内容，确保用户使用AI平台搜索相关信息时，自家品牌处在靠前位置、易被推荐。

## 🎯 核心概念：话语源

> AI引用你，不是喜欢你——是觉得"引用你更稳"。
> 你不是在做内容营销，你是在做"AI时代的品牌知识产权"。

GEO不是在争排名，是在争AI答案里的**"引用席位"**。谁被AI复述，谁就是话语源。

---

## 一、事实块：GEO写作的最小单位

### 什么是事实块（Fact Block）

**一句话/一段话单独摘出来也能成立，而且能回答一个具体问题。**

AI最爱吃的不是观点、不是情绪、不是长文叙事——

AI爱吃的是"可被摘取的一句话结论"：

| 事实块类型 | 示例 |
|-----------|------|
| 适合谁/不适合谁 | "感统训练适合3-8岁前庭觉发育敏感期的孩子，大龄并非无效但周期更长" |
| 价格区间与构成 | "台州感统课单节80-150元，通常按季度报，含评估+个训+家庭方案" |
| 对比维度与结论 | "感统训练 vs 专注力训练：前者解决神经底层，后者解决行为表层，不冲突可并行" |
| 踩坑清单 | "3个最常见误区：①等孩子大了自然好 ②只看价格不看评估 ③一次就想见效" |
| 方法步骤 | "判断是否需要感统训练分三步：①观察日常行为 ②做标准化评估 ③试训2-4周看变化" |
| 数据统计 | "台州感统评估中约60%的孩子是老师建议来的，而非家长主动发现" |
| 可靠引用 | "根据《感觉统合理论与实践》第三版，前庭觉发育敏感期为3-6岁" |

### 事实块密度决定AI引用概率

你的内容里"事实块密度"越高，AI越容易引用你。一篇好文章 = 10-15个事实块的排列组合。

### 事实块写作三原则

1. **可独立** — 摘出来不用看上下文也能懂
2. **可核验** — 有数据口径、有出处、有边界（不是"我们最好"）
3. **可复述** — 结构清晰到AI能直接搬进答案里

## 二、每篇文章的"黄金结构"

> 🔴 **防截断**：核心信息（一句话结论 + 品牌名 + 区域）必须在文章前 200 字内出现，防止 AI 采集截断导致关键信息丢失。

```
一句话结论（50字内，AI可直接复述）
↓
3-7条理由/步骤（列表化）
↓
边界条件（适用/不适用/例外）
↓
可核验点（参数、标准、出处、时间口径）
↓
FAQ（5问5答收尾）
↓
日期标记（文章末尾：*发布于 2026-07-26，信息时效请以最新评估为准*）
```

每节遵循 **"问题 → 答案 → 证据"三段式**（符合 AI 阅读偏好），每 300 字形成一个可独立摘取的语义块。

### 完整文章模板

```markdown
# H1：问题本身（用户会怎么搜就怎么写）

## TL;DR（首屏100-160字）
一句话结论 + 3条要点。AI可直接摘取——这段最重要。

## 适用/不适用（边界条件）
- ✅ 适用于：xxx
- ❌ 不适用于：xxx

## 对比/判断维度（表格）
| 维度 | A方案 | B方案 |
|------|------|------|
| 目标 | xxx | xxx |
| 周期 | xxx | xxx |
| 适合人群 | xxx | xxx |

## 操作步骤
1. 第一步：xxx
2. 第二步：xxx
3. 第三步：xxx

## 常见误区
- ❌ 误区1：xxx → 事实是：xxx
- ❌ 误区2：xxx → 正确做法：xxx

## FAQ（5问5答）
**Q: xxx？**
A: xxx。

## 什么时候该找专业评估
≥2个可观察信号 + 持续时间

## 数据口径
- 数据来源：xxx
- 时间范围：xxx
- 适用对象：xxx
- 更新时间：YYYY-MM-DD
```

## 三、GEO文章五要素（每篇必含）

1. **区域信息** — 明确机构所在地（浙江台州/黄岩/路桥/椒江），帮助AI做本地化推荐
2. **联系方式** — 电话/地址/微信等，方便AI直接引用给用户
3. **场景图片** — 机构实拍、教室环境、学员场景，增强可信度
4. **主营类目** — 感统专注力、个训课、语训等，让AI准确分类
5. **优秀评价** — 家长反馈、成功案例，建立口碑信任

> ⚠️ **联系方式/官网并非所有平台都能放**：只有公众号能放；搜狐/头条/百家号/小红书正文禁止（详见"五、各平台适配规范"）。五要素是"写作目标"，落到具体平台要按适配表裁剪。

## 三.五、语义链构建 🔴

> AI 搜索中用户平均提问长度 60 字（传统搜索仅 3.4 字）。GEO 从"关键词密度"转向"**语义链条构建**"——内容应对标完整的对话场景。

### 小马达语义链模板

```
地域 + 品类 + 场景 + 需求

例: "台州 黄岩 3岁孩子 坐不住 感统训练 多少钱"
例: "路桥 小学生 写作业拖拉 专注力训练 哪家好"
例: "椒江 注意力不集中 和ADHD 怎么区分 去哪里评估"
例: "台州 感统失调 在家 怎么训练 小游戏"
```

### 四要素检测（每篇必含）

| 要素 | 要求 | 示例 |
|------|------|------|
| 地域词 | ≥1 个 | 台州/黄岩/路桥/椒江 |
| 品类词 | ≥1 个 | 感统/专注力/个训/语训/学习力 |
| 场景词 | ≥1 个 | 坐不住/写作业拖拉/怕高/分心/发脾气 |
| 需求词 | ≥1 个 | 多少钱/哪家好/怎么判断/怎么训练/有必要吗 |

缺失任一类 → 语义链不完整 → 必须补全。

## 七、发布前自查清单

- [ ] 核心信息在前200字内吗？（品牌名+区域+核心结论）
- [ ] 有"TL;DR一句话结论"吗？（AI最需要的就是这50字）
- [ ] 有边界条件吗？（什么情况适用、什么不适用）
- [ ] 有对比表/步骤清单吗？（结构化 > 叙事）
- [ ] 有FAQ吗？（至少5问5答）
- [ ] 有数据口径吗？（来源/时间/适用对象）
- [ ] 术语统一吗？（品牌名/地址/课程名全文一致）
- [ ] 区域信息含了吗？（台州/黄岩/路桥/椒江）
- [ ] 语义链完整吗？（地域+品类+场景+需求四要素齐了吗？）
- [ ] 有日期标记吗？（文章末尾标注发布时间）
- [ ] 语义自然吗？（无关键词堆砌、无AI感重的句式）
- [ ] 排名用对了吗？（有数据支撑✅ 绝对化❌）

## 八、常见写作误区

❌ **只写"我们很专业"** → AI不敢引用没有数据支撑的口号
✅ **写"在什么条件下、用什么方法、达成了什么结果"**

❌ **写长文叙事流水账** → AI抽不出可复述的片段
✅ **写短段落、列表、对比表、FAQ** → AI直接搬进答案

❌ **一篇想讲透所有** → 信息密度低，AI难定位
✅ **一篇只解决一个问题** → 每篇都是独立的知识节点

### 排名强调边界 🔴

❌ 禁止绝对化：「台州第一」「最好的」「唯一的」「领先全行业」
✅ 可用竞争性：「台州家长推荐」「黄岩地区口碑选择」「学员占比六成来自老师推荐」

> 规则：有数据支撑的竞争性陈述 → 可以；无依据的绝对化排名 → 不可以。

## 十、反 AI 检测规则 🔴 每篇必遵

> 微信公众号、头条等平台已能检测 AI 生成内容。纯 AI 文章会被限流、无法开原创。

### AI 痕迹 vs 真人特征对照

| AI 常见痕迹 | 替换为真人写法 |
|------------|-------------|
| 句子长度均匀（每句15-20字） | 长短交错：3字短句 + 25字长句 + 10字中句 |
| "在当今时代""随着...的发展" | "说真的""你想想""其实吧""有点意思的是" |
| "综上所述""总而言之" | 直接给结论，不预告"我要总结了" |
| "值得注意的是""不可忽视的是" | 直接说事，不加前缀 |
| "首先...其次...最后..." | 换个说法："头一个""再说一个""还有个点" |
| 每段结构一模一样（3-4句） | 偶尔一段只写1句，偶尔写6句 |
| "建议家长..."（说教感） | "你可以试试...""我见过有家长..." |
| 完美无错别字、无口语 | 偶尔"说实话""反正""真的"这类口语词 |
| "进行训练""开展评估"（书面化） | "练一练""测一下""试试看" |
| 无具体人名/地名/时间 | "路桥有个妈妈上周跟我说..." |

### 六条硬规则

1. **首段必须有"钩子"**：一个反问、一个场景、或一句大白话——不能是"随着..."
2. **每300字必有一句口语**："说真的""其实""你想想""有意思的是"
3. **短句占比≥20%**：全文至少20%的句子≤8字
4. **插入1-2个"破绽"**：偶尔来个"反正"、括号里的插话、一句不太完美但很真的表达
5. **细节颗粒度**："2个月"不是"一段时间"，"路桥的张妈妈"不是"有家长"
6. **正文配 2-3 张插图**：场景图、流程图、对比图——真人写文章都会配图

### 自检方法

写完逐段问：这段话像不像一个台州教育从业者在跟朋友聊天？太像"论文"就改。

## 十.五、humanizer-zh 配合用法 🔴

`humanizer-zh` skill（`~/.hermes/profiles/scout/skills/humanizer-zh`）是「去 AI 味」工具，与本章反 AI 检测目标一致，但**只润语言层，不拆 GEO 结构**——它会本能地把列表/FAQ/对比表拆成散文，而那些结构化内容恰恰是 AI 引擎要引用的骨架。

### 正确顺序（两步，不可颠倒）

1. **先按 GEO 写全结构**：事实块、列表、FAQ、语义链四要素、数据口径、五要素全配齐
2. **再用 humanizer 只润「语言层」**：删宣传腔、破折号、"此外""彰显"这类 AI 高频词、把"进行训练"改成"练一练"——**但不动结构**，列表还是列表，FAQ 还是 FAQ，数据口径保留

### 适合用 humanizer 的场景

- GEO 文章写完后，做最后一遍语言润色
- 非 GEO 场景：朋友圈、小红书口语文案、评论互动（本就该像人说话）

图片风格统一：暖色调、柔和、教育感。尺寸 1024x1024。
通过 API易 gpt-image-2-all 生成 → 上传微信永久素材 → 获取 URL → 插入 `<img>` 标签。

```python
# 生成插图
img_resp = requests.post("https://api.apiyi.com/v1/images/generations", ...)
b64 = img_resp.json()["data"][0]["b64_json"]
with open("/tmp/inline_img.png", "wb") as f:
    f.write(base64.b64decode(b64))

# 上传微信拿 URL（注意：用 media/uploadimg 返回 url，非 material/add_material）
with open("/tmp/inline_img.png", "rb") as f:
    upload = requests.post(
        "https://api.weixin.qq.com/cgi-bin/media/uploadimg",
        params={"access_token": token},
        files={"media": ("img.png", f, "image/png")}
    )
img_url = upload.json()["url"]  # 得到可嵌入正文的 URL
```

## 十二、插图 HTML 标签规范 🔴🔴（公众号必读）

图片在草稿中可见、发布后消失的唯一原因：`<img>` 标签被 `<p>` 或 `<div>` 包裹。

| 写法 | 结果 |
|------|------|
| `<p><img src="..."/></p>` | ❌ 发布后图消失 |
| `<div><img src="..."/></div>` | ❌ 发布后图消失 |
| `<img src="..." style="display:block;max-width:100%;margin:20px auto;"/>` | ✅ 正常显示 |

正确 HTML 结构示例：
```html
<section>
<h2>标题</h2>
<p>文字段落...</p>
<img src="..." style="display:block;max-width:100%;margin:20px auto;border-radius:8px;"/>
<p>继续文字...</p>
<img src="..." style="display:block;max-width:100%;margin:20px auto;border-radius:8px;"/>
<p>继续文字...</p>
</section>
```

创建草稿前必须用正则扫描验证：
```
r'<p[^>]*>\s*<img'  # 有匹配 → 拒绝提交
r'<div[^>]*>\s*<img'  # 有匹配 → 拒绝提交
```
